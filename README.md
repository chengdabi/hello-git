# hello-git

一个用来练习 Git 操作的最小仓库。

## 这是什么

本地练习用：验证「初始化 → 提交 → 连接远程 → 推送」整条链路。

## 怎么跑

```bash
g++ main.cpp -o main
./main
```

## 目录

```text
hello-git/
├── main.cpp      # 示例程序
├── .gitignore    # 忽略编译产物
└── README.md
```
